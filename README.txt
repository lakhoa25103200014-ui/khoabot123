BOTTAOOGLE_BOT WEBSITE

Files:
- index.html: website content
- style.css: styling
- config.js: Telegram usernames
- script.js: navigation and link behavior
- zalopay-qr.png: optional QR image; add your own image with this exact filename

IMPORTANT:
The bot username is currently set to Bottaogoogle_bot in config.js, based on your request. If Telegram says "Username not found", the username may be different or the bot may not exist. Verify the exact username in BotFather and update TELEGRAM_BOT_USERNAME. Do not include @ in config.js.

To configure admin contact, replace THAY_USERNAME_ADMIN with the admin's real Telegram username (without @).

GitHub Pages:
1. Upload index.html, style.css, config.js and script.js into the repository root.
2. Optionally upload your QR image as zalopay-qr.png.
3. In GitHub repository, open Settings > Pages.
4. Select Deploy from a branch, branch main, folder /(root), then Save.
5. After deployment, refresh the website with Ctrl+F5.

The website is static; your Python Telegram bot must run separately.
